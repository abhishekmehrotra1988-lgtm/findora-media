# Findora shopping page deployment

The landing page is in `docs/index.html` in this public repository.

To publish it using GitHub Pages:
1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, set **Source: Deploy from a branch**.
3. Choose **main** and **/docs**, then click **Save**.
4. Wait for the Pages deployment to finish and verify the URL shown by GitHub.
5. Only after confirming the website works, use its URL in Findora's Instagram bio.

Expected Pages URL based on repository naming (not confirmed active): `https://abhishekmehrotra1988-lgtm.github.io/findora-media/`.

The four cards intentionally have **no product photographs or exact price claims** because retailer identity, rights and stock are not fully verified. The cards use user-provided shopping short links.

The site is NOT evidence of published Instagram posts. Day 1 is still `publication_authorized:false` in the private content plan.
